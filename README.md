## 🧠 Overview  

**MuseAI** is an intelligent, voice-enabled knowledge companion that helps you **talk to your data**.  
Upload PDFs, notes, or research papers — MuseAI reads them, understands them, and answers your questions conversationally.  

Powered by **RAG (Retrieval-Augmented Generation)**, **local LLMs**, and **voice interaction**, MuseAI bridges human creativity and artificial understanding — built for learners, researchers, and innovators who want privacy, speed, and beauty in one place.  

---

## ✨ Key Features  

| Feature | Description |
|----------|-------------|
| 🧩 **Retrieval-Augmented Generation (RAG)** | Understands your files and answers with real context. |
| 🗣 **Voice Interaction** | Ask questions via **Whisper STT**, hear answers via **Moshi / XTTS**. |
| 💬 **Conversational Memory** | Maintains multi-turn chat history for natural flow. |
| 🔍 **Vector Search** | Uses **FAISS/ChromaDB** for fast, semantic document lookup. |
| 🎨 **Modern UI** | Sleek React + Tailwind interface with dark/light mode. |
| 🔐 **Privacy-First** | Works fully offline with **Ollama / Mistral**. |
| 🧠 **Summarizer Mode** | Create summaries, notes, or blog drafts automatically. |
| 📊 **Insight Visualizer** | Displays how chunks were retrieved and ranked for transparency. |
